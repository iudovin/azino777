# Решение

Архитектура построена на базе Docker-контейнеров с автоматической инициализацией метаданных, ELT-пайплайнов и BI-дашборда. Вся установка (включая исходные данные и визуализацию) выполняется одной командой, дополнительно ничего докидывать не нужно

## 1. Стек 

* **СУБД:** PostgreSQL (версия 13)
* **ETL:** Apache Airflow (версия 2.9.2), DBT
* **BI:** Apache Superset

## 2. Установка и запуск

Развертывание проекта выполняется из корневой директории командой:

```bash
docker compose up -d --build
```

Авторизация везде по кредам `admin`/`admin`

## 4. Порядок запуска DAG-ов в Airflow

После поднятия стека откройте Airflow (`http://localhost:8080`) и активируйте конвейеры **строго в следующем порядке**:

1. **`00_init_dwh`** (разовый запуск руками):
* Применяет базовую структуру DDL: схемы (`raw`, `dds`, `dm`), первичные/внешние ключи, констрейнты и индексы
* **Внимание!** Повторный запуск сносит и пересобирает БД с нуля

2. **`01_monthly_increment`** (ежемесячный запуск, работает автоматически):
* Импортирует csv-файлы в raw, идемпотентно обновляет dds и dm
* Повторные запуски не приводят к дублированию или искажению данных


## 5. Архитектура хранилища и документация таблиц

Хранилище организовано по трехслойной модели:

* **`raw` (Сырой слой):** точные копии CSV-файлов со строковыми типами для бесперебойного потокового импорта.

* **`dds` (Детальный слой):** реляционная нормализованная модель с типизацией, проверками целостности (PK/FK), индексами и конвертацией финансовых показателей в USD.

* **`dm` (Слой витрин):** аналитическое представление для отчетности и дашбордов, агрегированное по странам и месяцам.

### Слой DDS (Детальный слой)

#### `dds.dim_providers`

| Поле | Тип | Описание |
| --- | --- | --- |
| `provider_id` | `INT` (PK) | Первичный ключ провайдера. |
| `provider_name` | `VARCHAR(100)` | Наименование игрового/платежного провайдера. |

#### `dds.dim_games`

| Поле | Тип | Описание |
| --- | --- | --- |
| `game_id` | `INT` (PK) | Первичный ключ игры. |
| `game_name` | `VARCHAR(100)` | Наименование игры. |
| `provider_id` | `INT` (FK) | Внешний ключ на провайдера (`dds.dim_providers`). |

#### `dds.dim_players`

| Поле | Тип | Описание |
| --- | --- | --- |
| `player_id` | `INT` (PK) | Уникальный идентификатор игрока. |
| `registration_date` | `DATE` | Дата регистрации игрока. |
| `registration_type` | `VARCHAR(50)` | Канал / тип регистрации. |
| `country` | `VARCHAR(10)` | Страна профиля (покрыта индексом `idx_dds_players_country`). |

#### `dds.fct_deposits`

| Поле | Тип | Описание |
| --- | --- | --- |
| `deposit_id` | `INT` (PK) | Первичный ключ транзакции депозита. |
| `player_id` | `INT` (FK) | Внешний ключ на игрока (`dds.dim_players`). Индексирован. |
| `deposit_date` | `DATE` | Дата депозита. Индексирована. |
| `provider_id` | `INT` (FK) | Внешний ключ на провайдера (`dds.dim_providers`). |
| `amount` | `DECIMAL(15, 2)` | Номинальная сумма операции. |
| `currency` | `VARCHAR(10)` | Исходная валюта операции. |
| `amount_usd` | `DECIMAL(15, 2)` | Нормализованная сумма в USD на дату транзакции (Forward-fill). |

#### `dds.fct_withdrawals`

| Поле | Тип | Описание |
| --- | --- | --- |
| `withdrawal_id` | `INT` (PK) | Первичный ключ транзакции вывода средств. |
| `player_id` | `INT` (FK) | Внешний ключ на игрока (`dds.dim_players`). Индексирован. |
| `withdrawal_date` | `DATE` | Дата вывода средств. Индексирована. |
| `provider_id` | `INT` (FK) | Внешний ключ на провайдера (`dds.dim_providers`). |
| `amount` | `DECIMAL(15, 2)` | Номинальная сумма вывода. |
| `currency` | `VARCHAR(10)` | Исходная валюта операции. |
| `amount_usd` | `DECIMAL(15, 2)` | Нормализованная сумма в USD на дату операции (Forward-fill). |

#### `dds.fct_games`

| Поле | Тип | Описание |
| --- | --- | --- |
| `game_transaction_id` | `INT` (PK) | Первичный ключ игровой ставки. |
| `player_id` | `INT` (FK) | Внешний ключ на игрока (`dds.dim_players`). Индексирован. |
| `game_date` | `DATE` | Дата игровой транзакции. Индексирована. |
| `provider_id` | `INT` (FK) | Внешний ключ на провайдера (`dds.dim_providers`). |
| `game_id` | `INT` (FK) | Внешний ключ на игру (`dds.dim_games`). |

| `currency` | `VARCHAR(10)` | Исходная валюта ставки. |

### Слой DM (Слой витрин)

| `report_month` | `DATE` | Отчетный месяц (первое число месяца среза: `YYYY-MM-01`). |

| `sum_withdrawals_usd` | `DECIMAL` | Суммарный объем выводов средств в USD за месяц. |
